# Powergym System

Sistema integral de gestión para gimnasios.

## ✨ Funcionalidades recientes
- **Módulo de Coach:** Implementación completa de creación y visualización de rutinas.
- **Asignación de Rutinas:** Ahora los entrenadores pueden asignar rutinas específicas a los miembros.
- **Gestión de Puertos:** Configuración optimizada (5174/3001) para evitar conflictos.
- **Base de Datos:** Inicialización automática de tablas y backup actualizado en `/database`.

## 🚀 Inicio rápido
1. Clonar el repo.
2. Instalar dependencias: `npm install` (en raíz y backend).
3. Configurar `.env` en `/backend`.
4. Ejecutar: `npm run start:server` y `npm run dev`.
